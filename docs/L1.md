| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | starter หลักที่ดึงชุด library สำหรับเขียนและรัน test มาให้ครบในตัวเดียว|
| junit-jupiter | ใช้เขียนและรัน unit test ด้วย @Test (JUnit 6)|
| assertj-core |	ใช้เขียนคำสั่งตรวจสอบผลลัพธ์ (assertion) ที่อ่านเข้าใจง่าย |
| mockito-core | ใช้สร้าง test double (mock) เพื่อแยกส่วนที่ต้องการทดสอบออกจากส่วนอื่น|
| hamcrest |คลัง matcher สำหรับช่วยตรวจสอบเงื่อนไขและเปรียบเทียบค่าในการทำ test |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
    พิสูจน์ว่าชุดทดสอบ (test) ที่เราเขียนทำงานได้จริงและสามารถตรวจจับข้อผิดพลาดได้เมื่อโค้ดยังไม่ถูกต้อง หากเห็นแต่ green bar อย่างเดียว เราจะไม่สามารถมั่นใจได้เลยว่าที่ผ่านเป็นเพราะโค้ดทำงานถูก หรือเป็นเพราะ test เขียนผิดจนไม่ได้ตรวจอะไรเลย

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
